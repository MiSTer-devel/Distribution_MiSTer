# GameKing core

## Setup

This core is the Timetop GameKing, a truely awful chinese handheld. Notably, this the GameKing I/II. There was a GameKing III but it was a completely different console with a bizzare hexagonal pixel screen and 3 really bad games, which is not represented here. To set this up, put the GameKing bios as boot0.rom in the GameKing game folder.

## QA

Not gonna lie, I didn't have much to compare this to, but the 65c02 is heavily tested for accuracy at least. The console itself is rare and the chips are all epoxy glop-top junk. All the games run except the bad-dumped x-in-1 games and the two dumped GameKing III games.
