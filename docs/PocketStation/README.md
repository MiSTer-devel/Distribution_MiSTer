# PocketStation MiSTer

## Setup
Not much. The game files should be placed in the PocketStation games folder. GME files tend to be the cleanest with the protos and such being properly wrappered for execution.

## Features
You can save states and mount Playstation `.sav` files. There's an option to load and write Playstation memory cards via SNAC.

## QA
The arm chip was based loosely on the chip from the GBA core. It was tested pretty heavily with a variety of bench tools. There's not a ton more to this system. All the games run except the ones with DRM, though not all of them are especially useful without playstation hardware attached.
